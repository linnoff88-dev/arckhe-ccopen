☁️ O que é OpenRouter

OpenRouter é um gateway de API unificado que dá acesso a dezenas de modelos LLM diferentes através de um único endpoint. Em vez de gerenciar múltiplas contas e chaves de API, você usa apenas um ponto de acesso para GPT, Claude, Llama, Mistral, Qwen e mais.

☁️ Conceito: Marketplace de APIs

Pense no OpenRouter como um "shopping center" de modelos de IA. Você vai a um único lugar e tem acesso a todos os fornecedores:

  • •OpenAI — GPT-4o, GPT-4o mini
  • •Anthropic — Claude Sonnet, Claude Haiku
  • •Meta — Llama 3.1, Llama 3.3
  • •Mistral — Devstral, Mistral Large
  • •Alibaba — Qwen3-Coder, Qwen2.5
  • •DeepSeek — V3.1, R1

📊 Dados

  • 100+ modelos disponíveis no catálogo
  • API compatível com OpenAI — zero mudança de código para migrar
  • Endpoint único: https://openrouter.ai/api
  • Modelos :free disponíveis sem custo por token
2

💰 Tier Gratuito

O OpenRouter oferece um tier gratuito generoso com modelos identificados pelo sufixo :free. Esses modelos custam literalmente $0 por token — você pode usar sem adicionar cartão de crédito ou créditos à conta.

💡 Dica Importante

Modelos com sufixo :free custam $0 por token. Isso significa que você pode fazer milhares de chamadas sem pagar nada. A distinção é clara no nome do modelo: qwen/qwen3-coder:free vs qwen/qwen3-coder (pago).

Comparativo de Limites por Plano

Situação Req/dia (modelos :free) Custo
Sem créditos ($0) 50 req/dia $0
Com $10+ em créditos 1000 req/dia $0 (créditos não consumidos)
3

📊 Limites de Uso

Os limites diários existem para evitar abuso do tier gratuito. O contador reseta à meia-noite UTC todos os dias. Para a maioria dos desenvolvedores, 50 req/dia é suficiente para sessões normais de trabalho.

⚠️ Atenção

O limite diário reseta à meia-noite UTC. Se você atingir o limite no início do dia, precisará esperar até a virada. Planeje sessões longas de desenvolvimento para quando tiver mais requests disponíveis.

💡 Estratégia Recomendada

Adicionar $10 uma vez à conta libera limites maiores permanentemente. Os créditos não são consumidos pelos modelos :free — eles apenas desbloqueiam o limite de 1000 req/dia.

  • ✓$10 depositado = 1000 req/dia para sempre
  • ✓Créditos ficam disponíveis caso queira usar modelos pagos
  • ✓Pode levar meses para gastar $10 em uso ocasional de modelos pagos

👤 Criando Conta

Criar uma conta no OpenRouter é simples e não requer cartão de crédito para o tier gratuito. Siga os passos abaixo:

1

Acesse openrouter.ai

Passo inicial

Abra o navegador e acesse https://openrouter.ai. A página inicial mostra os modelos disponíveis e os preços.

2

Clique em Sign Up

Criação de conta

No canto superior direito, clique em Sign Up. Você pode criar conta com email ou usar login social (Google, GitHub).

3

Verifique o email

Verificação obrigatória

Você receberá um email de verificação. Clique no link para confirmar sua conta. Sem verificação, não é possível gerar API keys.

4

Acesse o dashboard

Conta pronta

Após verificar, você terá acesso ao dashboard em openrouter.ai/settings onde gerencia chaves, créditos e monitora uso.

6

🔑 Gerando API Key

A API Key é seu token de autenticação. Ela começa com sk-or- e é exibida apenas uma vez no momento da criação — guarde-a imediatamente.

1

Acesse o Dashboard

Vá para openrouter.ai/settings/keys ou navegue pelo menu: Settings → API Keys.

2

Clique em Create Key

Dê um nome descritivo à chave (ex: "claude-code-dev") e clique em Create.

3

Copie e guarde imediatamente

A chave aparece no formato sk-or-v1-xxxxxxxxxxxxxxxx. Copie-a agora — ela não será mostrada novamente.

🔒 Segurança da API Key

  • ✗Nunca compartilhe sua chave publicamente (GitHub, fóruns, redes sociais)
  • ✗Não commite a chave em repositórios git
  • ✓Use variáveis de ambiente ou o settings.json do Claude Code
  • ✓Se vazar, revogue imediatamente no dashboard e gere uma nova
